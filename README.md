# Distributed Wagering Processor

We will build a distributed wagering processing system with NestJS and TypeScript, focusing on reliability and scalability.

The project is in its initial stage, with the application scaffold and development and testing tools configured.

[GitHub repository](https://github.com/joaoalberto-dev/distributed-wagering-processor)
[Project](https://github.com/users/joaoalberto-dev/projects/3)

## Development

```bash
bun install
bun run start:dev
```

## Checks

```bash
bun run typecheck
bun run lint
bun run format
```

## Tests

```bash
bun test          # all tests
bun run test      # unit tests in src/
bun run test:e2e  # end-to-end tests in test/
bun run test:cov  # unit test coverage
```
